# 🌿 Plant World

A simple and clean multi-page website that explores the fascinating world of plants and highlights their importance in our daily lives.

Built using **HTML**, **CSS**, and a bit of **JavaScript**, this project demonstrates a foundational web design concept and is ready for further development.

## 📋 Pages

- 🏠 **Home** – Introduction and overview  
- 🌱 **Plants** – Highlights plant types (currently includes one example)  
- 🛠️ **Services** – Describes services (currently one sample service)  
- 📬 **Contact** – Contact information or form

## 🌟 Project Goal

The website is intended to present key types of plants from around the world and to raise awareness of the vital role plants play in our environment.

Although it currently includes one plant and one service, the structure is designed to be easily **expandable and customizable**.

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (used for a "scroll to top" button functionality)
- **sidebar menu button** using JavaScript for better navigation on small screens  
- **Responsive Design** — optimized for small screens and mobile devices 📱
- **Hosted online** via [GitHub Pages](https://rami-div-git.github.io/Plants-World/)
